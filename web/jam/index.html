Gestures & keys

Chords mode

  • Left hand fingers pick the chord: ☝ 1 = I (C) · ✌ 2 = ii (Dm) · 3 = iii (Em) · 4 = IV (F) · 🖐 5 = V (G)
  • Fist stops the chord
  • Right hand height = volume · tilt = tone
  • Right pinch = sustain (hold the chord) · move right = inversions
  • Keys 1–7 chords, 0 stop

Melody mode

  • Move left / right = lower / higher note (follow the note strip)
  • Pinch = play the note, release = stop
  • Height = dynamics · tilt = tone
  • Fist held briefly = silence
  • Keys A S D F G H J K L

Rhythm mode

  • Pinch in the left / middle / right zone = kick / snare / hi-hat
  • Loop rec + beat on = hits are written into the loop
  • Keys Z kick, X snare, C hi-hat

Anywhere: point your index finger at a mode button for a second to switch modes (one-handed). Q/W/E modes · Space beat · ↑↓ volume · ←→ tone · M mute · R record · V visual style · Esc all notes off.
